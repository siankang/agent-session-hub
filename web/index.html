这个工具做什么

扫描本机各个 AI Agent 客户端（WorkBuddy、Claude Code、Codex、Qoder、TRAE、CodeBuddy、Devin 等）落地在用户目录与 AppData 下的会话、消息与数据文件，把不同格式归一成统一的会话索引，在这个独立桌面窗口里查看、搜索、分析占用与导出。全部功能都不需要浏览器或网址。启动时（或点顶栏「重新扫描」）会做一次统一识别，同时生成会话索引与清理候选，两处数据同步就绪。

⚠️ 只读承诺：本工具对源文件只做读取，不修改、不移动、不删除任何 Agent 客户端的数据。所有派生数据写在本项目目录的 data/index.db。

三个识别级别

完整解析 已读出逐条对话，可查看全文与全文搜索。
仅清单 已识别会话标题 / 时间 / 路径，但对话正文存在未解析的容器里。
仅体量 只识别到数据目录，报告文件数与占用体积。

桌面窗口模式

双击 exe 即打开独立软件窗口：不启动浏览器、不显示网址、不监听任何端口。界面与 Python 内核通过进程内桥接直连，数据不出本机；关闭窗口即退出。窗口可自由缩放，左侧导航切换六大功能页。

导出的文件默认保存在软件目录的 exports/（会先弹出系统「另存为」对话框），清理备份在 backup/quarantine/。

高级用途：源码目录下的 python app.py 仍可启动服务模式用于调试，但日常使用完全不需要它。

⚠️ 隐私提醒：索引库 data/index.db 以及 exports/、backup/ 都含有对话文本副本，请勿随意外传。若曾手动启用服务模式的局域网访问，同网段设备可读取被索引的对话内容。

新增一个客户端

在 core/adapters.py 的 SOURCES 注册表里加一条配置：指定 roots（数据目录）、parser（jsonl / workbuddy / codex / vscdb / sqlite_meta / jsonmeta / aggregate）与 flavor（消息格式）。若是一种全新格式，在 extract_line() 里加一个分支即可，其余模块无需改动。

导出

会话列表页可把当前筛选结果导出为 Markdown 清单（不含消息正文，上限 1000 个会话）；点开某个会话后可单独导出该会话的 Markdown（含全部消息）或 JSON。批量导出不含正文，避免一次生成超大文件。桌面模式下会弹出系统「另存为」对话框，取消则自动保存到 exports/。

清理功能

清理页把本机会话 / 记忆 / 缓存 / 会话数据库分成四类做只读分析，标注体积、风险与保护原因。软件不会自动改动任何文件；要执行清理只需：逐项勾选 → 生成计划并核对完整路径 → 输入「确认清理」 → 完整备份并校验 → 每批最多 10 项移入 Windows 回收站（失败立即停止）→ 可按批次还原。没有额外解锁步骤，确认词是唯一关卡。

⚠️ 此操作非常危险，可能导致不可逆的数据丢失！
会话与记忆一旦被客户端覆盖或回收站被清空就无法找回。工具不会自动清理任何文件，也不会替你决定删什么；身份文件、登录状态、本工具目录与系统个人目录一律受保护。建议先关闭对应客户端，并保留 backup/quarantine/ 备份。

已知边界

体量统计对每个来源最多抽样 20000 个文件，并跳过缓存 / node_modules / 运行时目录，超大目录可能低估；云端会话（豆包、即梦、Coze 等）本地通常只有缓存，无法还原对话。中文全文检索由 FTS5 与子串匹配双路合并，未做语义分词。

诊断脚本

tools/ 下的只读诊断脚本用于探查新客户端的数据落地位置与文件结构，输出路径、键名与类型，不输出任何对话正文。
